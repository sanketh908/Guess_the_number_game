This is a simple number guessing game developed in Android Studio. The game generates a random number, and the player must guess the correct number within a limited number of attempts. It features multiple difficulty modes including Easy, Medium, and Hard, each offering different number ranges and challenge levels. In addition, the game includes a special Custom Round mode that allows players to set their own number range for a personalized experience. After each guess, the app provides feedback indicating whether the number is too high, too low, or correct. This project demonstrates core Android development concepts such as random number generation, user input handling, game logic implementation, and interactive UI design in a fun and engaging way.
